## 📱 Task 1: SMS Spam Detection & Filtering System

### 🔍 Problem Statement
In modern digital communication, the surge of promotional bots, SMS phishing (smishing), and unsolicited text advertisements significantly compromises user privacy and mobile device security. Manually triaging text payloads is highly inefficient and creates user security liabilities. This creates a critical need for an automated, lightweight security application capable of analyzing text strings in real-time and classifying malicious content before it interacts with the user.

### 🎯 Project Objective
To design and deploy an end-to-end Machine Learning pipeline utilizing Natural Language Processing (NLP) to detect SMS spam. The system cleans raw text payloads, extracts numerical semantic features using *TF-IDF Vectorization, and trains an optimized **Multinomial Naive Bayes* classifier. The pipeline secures a *96.68% verification accuracy* and holds a *1.00 precision rate for malicious payloads*, ensuring zero critical user messages are mistakenly classified as spam.

### 📊 Model Performance Metrics
* *Overall Evaluation Accuracy:* 96.68%
* *Spam Detection Precision:* 1.00 (Zero false positives)
* *Spam Detection Recall:* 0.75

## Task 2: Advanced Customer Churn Prediction Engine

### Project Overview
Developed an end-to-end machine learning pipeline to predict customer churn for digital services using historical customer data, demographics, and active platform usage behavior.

### Feature Engineering & Framework Mappings
Rather than training standard baseline columns blindly, this project applies advanced consumer behavior framework mappings to standard attributes:
* *Gamification Habit Decay Index (game_boredom_index):* Quantifies active application traffic drops against premium loops.
* *Social Collective Purchasing Hub Cohesion (social_hub_score):* Tracks organic user network dependencies via team-bundle purchases.
* *Transactional Checkout Friction Susceptibility (checkout_friction_risk):* Pinpoints checkout drop-off indicators driven by payment engine failures.

### Model Execution & Performance Architecture
* *Framework:* Automated hyperparameter tuning using GridSearchCV optimized strictly for *Recall* to minimize unmitigated customer churn blindspots.
* *Performance Results:* Achieved an overall *Accuracy of 81%* with a *Positive Class Recall of 70%* and an *AUC-ROC Score of 0.85*, proving high predictive capability across imbalanced class distributions.

### Business Monetization Dashboard
The system converts abstract mathematical probability flags directly into an operational campaign workbook targeting major localized brands (e.g., Nykaa, Amazon India, Myntra) with specialized retention triggers, capturing a simulated 65% of at-risk revenue and calculating net monthly sales growth expansion via social referrals.
